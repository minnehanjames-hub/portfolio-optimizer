# Monte Carlo Portfolio Optimizer

## In plain terms

A browser-only tool that simulates how a portfolio of investments might perform over time. Enter your holdings (stocks, bonds, and other assets) with their expected returns and amounts, pick a time horizon, and it runs a **Monte Carlo simulation** — thousands of randomized future scenarios — to show the likely range of outcomes instead of a single guess.

## What it shows

- **Forward range** — median outcome and percentile bands for your portfolio's future value
- **Diversification** — effective number of holdings and concentration
- **Risk & performance** — return stats, information ratio, and alpha
- Plain-English interpretation of the results

## Run it

Open `index.html` in any browser — no install or build step.

## Note

An educational model for building intuition about risk and return — not investment advice.
